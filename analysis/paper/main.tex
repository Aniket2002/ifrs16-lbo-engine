\begin{abstract}
This note documents the currently reproducible outputs of the repository and removes non-regenerable fixed baseline, certification, sensitivity, and IRR-optimization result tables. The implementation combines a full annual cash-flow simulation with a reduced-form analytic screening model under IFRS-16 and frozen-GAAP covenant conventions. All reported artifacts in this document are generated by repository code.
\end{abstract}

\section{Scope and Implementation}

The repository provides two model families:
\begin{itemize}
\item Full simulation with explicit operating cash flow, lease principal cash payments, debt amortization, cash sweep, revolver usage, insolvency flags, and exit equity bridge.
\item Analytic screening path producing leverage and ICR paths, compared against full simulation as a speed/approximation diagnostic.
\end{itemize}

The benchmark risk output is named \texttt{analytic\_risk\_score}. It is used as a ranking score and calibration target in generated plots/reports. It is not described as a calibrated probability in this manuscript.

\subsection*{Accor Source and Reconstruction Metadata}

Each row in \texttt{data/case\_study/accor.csv} contains:
\begin{itemize}
\item \texttt{source\_report}: Accor Universal Registration Document
\item \texttt{source\_page}: operating lease / lease-note disclosure
\item \texttt{reconstruction\_formula}: lease\_expense = reconstructed lease footprint from disclosed lease obligations and rent note
\item \texttt{source\_note}: row-level provenance note (including explicit crisis-year handling for negative EBITDA)
\end{itemize}

\section{Accounting Mechanics Implemented in Full Simulation}

The simulation uses:
\begin{align}
L_{t+1} &= L_t + \text{additions}_t - \text{principal}_t, \\
\text{cash uses}_t &\supseteq \text{lease interest cash payment}_t + \text{lease principal cash payment}_t.
\end{align}

Entry capitalization includes explicit sources-and-uses fields (entry enterprise value, fees, debt source, cash source, sponsor equity). Equity cash-flow vectors, MOIC, and IRR are computed from sponsor equity contribution and simulated exit equity.
