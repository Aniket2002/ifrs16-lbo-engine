# Repository history

The repository evolved through three research stages.

- **v1** contained the original model and manuscript, including claims later found
  to be unsupported or overstated. It is superseded.
- **v2** corrected substantive financial-model and manuscript defects, archived a
  reproducible benchmark, and recorded a claim-by-claim revision audit. The v2
  source and reviewed artifacts remain as historical evidence.
- **v3** rebuilt the validation hierarchy around engine correctness, grouped
  threshold transfer, Bayesian admission, financing-design limits, claim
  governance, and a reproducible final manuscript. Repository cleanup and public
  documentation consolidation completed that lineage.

The authoritative research output is the v3 manuscript on `main`:
[**Ranking Is Not Threshold Portability: Validating IFRS 16 Covenant Screening in
a Synthetic Benchmark**](../paper/ifrs16_lbo_ssrn_v3.pdf).

For detailed history, see the [v2 revision audit](../paper/REVISION_AUDIT.md) and
the [recovered historical source](../paper/historical/). Git retains the complete
commit history; this summary does not replace those records.
