# Repository cleanup plan

This plan records the repository inventory before deletion. The cleanup branch
starts at canonical commit `8e69d4911d352c6572c2a083e99e216fa5179644`.
The pre-cleanup working tree contained 55,822 files in 6,578 directories,
totalling 1,607,445,643 bytes (1,532.98 MiB), of which 246 files were tracked.
The inventory covered every tracked path and all ignored or untracked paths
outside `.git`; local environments and caches were assessed as categories.

## Verification after cleanup

The cleanup will run Ruff lint and formatting checks, the non-stochastic full
test suite, the manuscript-freeze validator, the final manuscript audit, exhibit
rendering checks, and the documented v3 manuscript build. Protected v3 paths will
be compared byte-for-byte with the starting commit. Any deletion that proves to
be a dependency will be restored.
