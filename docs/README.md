# Documentation

The authoritative repository state is the validated v3 workflow and final paper
on `main`. This page separates the short reader-facing guides from the detailed
records retained for reproducibility and provenance.

## START HERE

1. Read the [final paper](../paper/ifrs16_lbo_ssrn_v3.pdf).
2. Review the [validation summary](VALIDATION_SUMMARY.md) for what the evidence
   supports and what it does not support.
3. Use the [reproducibility guide](REPRODUCIBILITY.md) to validate the repository
   or rebuild the manuscript.
